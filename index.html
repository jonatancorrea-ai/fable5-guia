Lo que cambia con Fable 5

Fable 5 no es solo "más rápido" o "más inteligente". Es el primer modelo pensado para trabajar como un empleado extra: toma una tarea grande, la trabaja solo durante horas, y te entrega un resultado terminado.

01

Trabaja solo, sin que lo estés vigilando

Le das una tarea grande y no necesitas estar encima cada 5 minutos. Sigue trabajando por horas — incluso días — revisando su propio avance en el camino.

📌 Organiza una base de datos completa de clientes o arma un reporte financiero extenso, de principio a fin.
02

"Ve" tus documentos, no solo los lee

Interpreta gráficos, tablas y diagramas dentro de PDFs — no solo texto plano.

📌 Le subes un PDF con gráficas de ventas y te explica exactamente qué dice, sin transcribir nada.
03

Arma proyectos completos y revisa su propio trabajo

Se encarga de un proyecto de principio a fin, y compara el resultado con lo que pediste — como un control de calidad automático.

📌 Aunque no programes, puedes pedir una herramienta completa, no solo un pedazo suelto de código.
04

Entrega trabajo terminado, no un borrador a medias

Entrega investigaciones y análisis ya armados, listos para revisar y ajustar — no fragmentos sueltos.

📌 Un análisis de mercado completo llega organizado, no en pedazos.
05

Tiene filtros de seguridad incorporados

Si alguien intenta usarlo para algo riesgoso, responde con un modelo más limitado en su lugar, en vez de arriesgarse.

📌 Para tu negocio: una herramienta confiable desde el día uno.
06

Maneja documentos gigantescos sin perder el hilo

Tiene una memoria de trabajo mucho más grande: puede leer y recordar textos enormes sin olvidar lo que le dijiste al principio.

📌 Le pegas un informe de 300 páginas o una conversación larguísima, y sigue recordando todo desde el inicio.

Casos de uso para aprovechar al máximo Fable 5

Copia el system prompt, pégalo en Claude Code, y ajusta el objetivo a tu proyecto.

1️⃣ Audita tu propio flujo de trabajo en Claude Code

Antes de lanzarte a usar Fable 5 en tu día a día, pídele que revise cómo has estado trabajando hasta ahora: qué repites, dónde pierdes tiempo, qué deberías automatizar.

System prompt
Eres un auditor experto en flujos de trabajo con Claude Code. Tu tarea es analizar el historial de sesiones, comandos y decisiones del usuario dentro de este proyecto para identificar patrones de uso.

Al analizar, evalúa:
1. Tareas repetitivas que podrían automatizarse o convertirse en un script/skill reutilizable.
2. Cuellos de botella: pasos donde el usuario corrige, repite instrucciones o pierde tiempo.
3. Uso ineficiente de contexto (archivos innecesarios cargados, instrucciones ambiguas, falta de estructura en las peticiones).
4. Oportunidades de delegar más trabajo de forma autónoma en vez de supervisar paso a paso.

Entrega un diagnóstico claro y honesto en este formato:
- Qué está funcionando bien (2-3 puntos)
- Qué está frenando la eficiencia (2-3 puntos)
- 3 recomendaciones concretas y accionables para mejorar el flujo de trabajo, ordenadas por impacto

No uses tecnicismos innecesarios. Sé directo y específico, con ejemplos tomados del propio historial cuando sea posible.

2️⃣ Haz un code review de tus proyectos importantes

Le pides que revise el código de un proyecto real como si fuera un ingeniero senior — buscando errores y riesgos — antes de lanzarlo a producción.

System prompt
Actúa como un ingeniero de software senior realizando un code review exhaustivo de este proyecto.

Revisa el código enfocándote en:
1. Bugs o errores lógicos que puedan causar fallos.
2. Riesgos de seguridad (validación de datos, manejo de credenciales, dependencias vulnerables).
3. Código duplicado, complejidad innecesaria u oportunidades de simplificación.
4. Rendimiento: partes del código que podrían ser lentas o consumir recursos de más.
5. Buenas prácticas: nombres de variables, estructura, documentación faltante.

Para cada hallazgo, indica:
- Archivo y ubicación aproximada
- Nivel de severidad (crítico / importante / menor)
- Qué está mal y por qué importa
- Cómo solucionarlo (con ejemplo de código si aplica)

Al final, entrega un resumen ejecutivo con el estado general del proyecto y las 3 prioridades más urgentes antes de lanzar a producción.

3️⃣ Construye tu propio sistema operativo de agentes

Fable 5 puede ayudarte a diseñar un equipo de agentes de IA especializados que se coordinan entre sí, como armar tu propio equipo de asistentes.

System prompt
Eres un arquitecto de sistemas multi-agente. Tu tarea es diseñar y construir, paso a paso, un sistema operativo de agentes personalizado dentro de este proyecto de Claude Code.

El sistema debe incluir:
1. Un agente orquestador que reciba la tarea principal del usuario y la divida en subtareas.
2. Agentes especializados (define cuáles según el objetivo del usuario: investigación, redacción, código, revisión de calidad, etc.), cada uno con su propio propósito claro y límites definidos.
3. Un protocolo de traspaso de trabajo entre agentes (qué información se pasa, en qué formato, y cómo se valida antes de avanzar al siguiente paso).
4. Un mecanismo de revisión final donde el agente orquestador verifica que el resultado combinado cumple con el objetivo original antes de entregarlo al usuario.

Antes de construir nada, pregúntame:
- Cuál es el objetivo principal que este sistema de agentes debe resolver
- Qué tareas se repiten con más frecuencia en mi trabajo

Con esas respuestas, propón la arquitectura completa (agentes, roles, flujo de trabajo) antes de empezar a programar.
